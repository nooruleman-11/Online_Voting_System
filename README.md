# Online Voting System

A simple C++ online voting system project.
This project is a simple C++ console-based online voting system. It demonstrates how to manage voter registration, cast votes, and display election results using a menu-driven interface.

## Project Overview

The voting system includes:
- Voter registration
- Vote casting for candidates
- Viewing registered voters
- Displaying election results
- Saving and loading data from files

This project is ideal for learning C++ fundamentals such as:
- input/output handling
- conditional logic and loops
- file operations
- simple data management
